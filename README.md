📊 DATA UBER – Prédiction des tarifs (Machine Learning)

📍 Associé à Asia Pacific University of Technology and Innovation (APU / APIIT)  Nov. 2025 – Déc. 2025

 Objectif du projet

Développement d’un modèle de Machine Learning capable de prédire les tarifs des courses Uber et Lyft à Boston à partir d’un jeu de données de plus de 690 000 trajets historiques.

L’objectif était de concevoir un modèle de régression performant permettant d’estimer le prix d’une course en fonction de variables contextuelles et environnementales.


🧠 Variables utilisées

  Distance du trajet

  Heure et moment de la journée

  Conditions météorologiques

  Variables liées à la demande


⚙️ Méthodologie

Pipeline complet :

   Nettoyage et préparation des données

   Analyse exploratoire (EDA)

   Feature engineering

   Entraînement et comparaison de modèles

   Évaluation des performances

Modèles testés :

  Régression Linéaire

  K-Nearest Neighbors (KNN)
  

🏆 Résultats
 Modèle	Performance
K-Nearest Neighbors	R² = 96,29 %
Erreur moyenne	~ 1,7 $

Le modèle KNN a démontré une excellente capacité prédictive et une forte généralisation sur les données.

🛠️ Technologies utilisées

Python · Pandas · NumPy · Scikit-learn · Matplotlib · Jupyter Notebook



💡 Compétences développées

 Construction d’un pipeline Machine Learning complet

Optimisation et comparaison de modèles
